# About me
I am Gerson Hauwanga
I graduated in electrical engineering from Brno University of Technology in 2026.
I build full-stack and embedded software, mostly in Python. I am based in Brno.

## Projects to look at first

- **[Berth](https://github.com/tymfly7/Berth)**: finds free parking spaces from camera feeds. PyTorch, FastAPI and React. It runs on a Raspberry Pi. This was my bachelor's thesis.
- **[Artificial Writer](https://github.com/tymfly7/artificial_writer)**: summarises web pages and PDFs from a command line, a desktop app or a web app. FastAPI, PostgreSQL, Redis and Docker Compose.
- **[AI Platform Lab](https://github.com/tymfly7/ai-platform-lab)**: a small AI platform with a model gateway, document search and access control. It runs locally with Docker.
- **[ESP32 plant sensor](https://github.com/tymfly7/Digital-Electronics-Project)**: a team project in MicroPython that shows sensor readings on an OLED and in a browser.
