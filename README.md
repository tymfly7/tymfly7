# 💫 About Me:
<br>I graduated in electrical engineering from Brno University of Technology in 2026.<br>I build full-stack and embedded software, mostly in Python. I am based in Brno.<br><br>## Projects to look at first<br><br>- **[Berth](https://github.com/tymfly7/Berth)**: finds free parking spaces from camera feeds. Stack: PyTorch, FastAPI and React. It runs on a Raspberry Pi. This was my bachelor's thesis.<br>- **[Artificial Writer](https://github.com/tymfly7/artificial_writer)**: summarizes web pages and PDFs through command line, desktop app or a web app. Stack: FastAPI, PostgreSQL, Redis and Docker Compose.<br>- **[AI Platform Lab](https://github.com/tymfly7/ai-platform-lab)**: a small AI platform with a model gateway, document search and access control. Runs locally with Docker. Uses Google Gemini API and Ollama Models.<br>- **[ESP32 plant sensor](https://github.com/tymfly7/Digital-Electronics-Project)**: a team project in MicroPython for indoor environment planting<br>## What I work with<br><br>- **Backend:** Python, FastAPI, PostgreSQL, Redis, Docker<br>- **Frontend:** React, TypeScript, Tailwind<br>- **Machine learning:** PyTorch, OpenCV, NCNN on Raspberry Pi<br>- **Embedded:** ESP32, MicroPython, C and C++ (coursework)<br>- **Testing:** pytest, ruff, mypy, GitHub Actions,<br>- **Others** JavaScript, HTML, CSS, Node.js, C#, Rust<br><br>## Contact<br>ggit@keemail.me<br>https://portfolio-v93u.onrender.com<br>
