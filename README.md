# About me
I graduated in electrical engineering from Brno University of Technology in 2026.
I build full-stack and embedded software, mostly in Python. I am based in Brno.

## Projects to look at first

- **[Berth](https://github.com/tymfly7/Berth)**: finds free parking spaces from camera feeds. Stack: PyTorch, FastAPI and React. It runs on a Raspberry Pi. This was my bachelor's thesis.
- **[Artificial Writer](https://github.com/tymfly7/artificial_writer)**: summarizes web pages and PDFs through command line, desktop app or a web app. Stack: FastAPI, PostgreSQL, Redis and Docker Compose.
- **[AI Platform Lab](https://github.com/tymfly7/ai-platform-lab)**: a small AI platform with a model gateway, document search and access control. Runs locally with Docker. Uses Google Gemini API and Ollama Models.
- **[ESP32 plant sensor](https://github.com/tymfly7/Digital-Electronics-Project)**: a team project in MicroPython for indoor environment planting
